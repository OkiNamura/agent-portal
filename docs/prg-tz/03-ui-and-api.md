# 03. Интерфейс и API

Документ описывает внешний контур: что видит игрок, какие действия ему доступны, какие
эндпоинты обслуживают эти действия, что происходит при сбоях. Критерии приёмки для этого
контура — блок 14 в `02-specs.md`.

## 1. Общая компоновка

```
┌───────────────┬──────────────────────────────────────────────────────────┐
│ боковое меню  │ рабочая область                                          │
│ 216 px        │                                                          │
│               │  экран (профиль / истории / мастер / агенты / статистика)│
│ ＋ Новая игра  │  или игра:                                               │
│ ◈ Профиль     │  ┌────────────────────────────────────┬────────────────┐ │
│ ▤ Истории     │  │ лента повествования                │ панель          │ │
│ ◉ Агенты      │  │ (прокрутка, ответы + метаданные)   │ состояния 318 px│ │
│ ∑ Статистика  │  │                                    │ (прокрутка)     │ │
│               │  └────────────────────────────────────┴────────────────┘ │
│ ASCII-карта   │  [полоса карточек сцены]                                 │
│ (только игра) │  [поле ввода] [→]                                       │
└───────────────┴──────────────────────────────────────────────────────────┘
```

Ширина ≤ 900 px: панель скрыта, кнопка «состояние» в шапке игры показывает её под лентой
(высота до 45 % экрана). Тема тёмная, одна; переключателя темы нет.

## 2. Экраны

| Маршрут | Назначение | Что видно | Источник данных |
|---|---|---|---|
| `#/profile` (по умолчанию) | Сводка игрока | карточка профиля, уровень (`ходы / 10`), XP-полоса, плитки «Историй», «Ходов», «Потрачено», «В игре»; блок «Продолжить» с последней кампанией и 4 последними событиями | `GET /api/stats` |
| `#/stories` | Список кампаний | строки: id, ход, место, стоимость, дата, статус «в игре»/«новая», кнопки «Продолжить», «Удалить» | `GET /api/campaigns` |
| `#/new`, `#/new/<presetId>` | Мастер новой игры | 4 шага: «Тон» (название + теги), «Мир» (описание), «Герой» (8 полей + «Случайный герой»), «Сборка» (обзор + «Собрать историю» + статус) | `GET /api/catalog`, `POST /api/generate/tone`, `POST /api/generate/world`, `POST /api/campaigns` |
| `#/agents` | Настройки семи агентов | селектор «Чьи настройки правим» (глобальные или игра), карточки агентов, блок «Теги иллюстратора» | `GET /api/agents`, `GET /api/agents?id=`, `PUT /api/agents/:id`, `POST /api/agents/:id/reset`, `POST /api/agents/:id/test`, `GET/PUT /api/art-tags` |
| `#/stats` | Расход и темп | плитки «Всего», «Ходов», «Средний ход», «Кэш», «Кадров»; таблица агентов; таблица кампаний с итоговой строкой | `GET /api/stats` |
| `#/play/<id>` | Игра | шапка, лента, панель, полоса карточек, ввод, карта помещения в меню | `GET /api/campaign/:id`, `POST .../turn`, `POST .../stream`, операции под ответом |

Кнопка «＋ Новая игра» ведёт сразу в мастер, а не в каталог пресетов. Каталог миров в PRG
пуст (`worlds.presets = []`), поэтому мастер всегда собирает мир из описания игрока.

## 3. Игровой экран

### 3.1. Шапка

- «←» — возврат к историям.
- Идентификатор кампании и строка «ход N · <место>».
- Текущая суммарная стоимость кампании (`$0.000000`).
- «🖼» — нарисовать кадр сцены.
- «состояние» — показать/скрыть панель (на мобильном панель появляется под лентой).

### 3.2. Лента повествования

| Тип элемента | Когда появляется | Содержимое |
|---|---|---|
| Системная строка | при открытии игры | «хроника «<id>» · ход N» |
| Реплика игрока | сразу после отправки, до ответа | текст ввода |
| Проза ведущего | по мере стрима или целиком | художественный текст |
| Метаданные ответа | после завершения хода | «ход N», «токены · кэш», стоимость, время, изменения, проблемы критика |
| Блок действий | под ответом ведущего | «⟳», «✎», «‹ n/m ›» при вариантах, «🖼» |
| Кадр | после генерации изображения | картинка под ответом |
| Врезка «новая карточка» | когда впервые появился персонаж | имя, роль, внешность, характер |
| Индикатор набора | пока ответ не начал приходить | три мигающие точки |

Лента не разбивается на страницы: при открытии рисуется весь лог. Длинные кампании
замедляют открытие — это известное ограничение PRG.

### 3.3. Поле ввода

- Многострочное, высота растёт до 160 px.
- Enter — отправить, Shift+Enter — перевод строки; пустой ввод игнорируется.
- Пока ход выполняется, кнопка «→» недоступна.
- Подсказка под полем: «Enter — отправить · Shift+Enter — новая строка».

### 3.4. Панель состояния

| Секция | Поля | Действия |
|---|---|---|
| Место и время | день и час, локация, погода | — |
| Тело | мастер-лист героя (или кнопка «✎ мастер-лист героя»), полоса здоровья, раны, состояния, эффекты (плюс/минус) | рисование мастер-листа |
| Деньги | «N з · N с · N м» | — |
| Снаряжение | имя × количество, место нахождения; карточка предмета | «◈» карточка предмета, «✕» выбросить |
| Пати | карточки: имя, роль, отношение, связь, внешность, характер, одежда, прошлое, заметка, отношения внутри пати; мастер-лист и портрет | «✎ мастер-лист», «◉ портрет» |
| Знакомые | те же карточки для NPC | то же |
| Задачи | заголовок, статус, «осталось N»/«срок вышел», шаги | «✓» выполнено, «↷» отказаться |
| Долги и крючки | обещания и последние 8 крючков с пометкой вида | — |
| Фракции | имя и отношение со знаком | — |
| Мир | раскрывающаяся «Карта мира» (ASCII) | — |
| Места | последние 8 знакомых мест | — |
| Бестиарий | имя, «опасность N» | — |
| Кадры | последние 4 изображения миниатюрами, ссылка на файл | — |
| Закрытое | «Архив · N», последние 25 записей с видом и причиной | — |

Секции «Пати», «Знакомые», «Задачи», «Долги и крючки», «Фракции», «Мир», «Места»,
«Бестиарий», «Кадры», «Закрытое» не рендерятся при пустых данных.

### 3.5. Полоса карточек сцены

Внизу над вводом — только персонажи с `present === true` и `status === 'alive'`: иконка,
имя, роль. Клик открывает панель и раскрывает карточку этого персонажа. Если в сцене никого
нет, полоса скрыта.

### 3.6. Карта помещения

ASCII-схема 31×12 в боковом меню под навигацией; видна только на экране игры; строится
на сервере и приходит в `map` (в ответе хода — тоже). Легенда: `#` стена, `.` пол, `@` ты,
`=` проход, `~` вода, `^` лестница, `*` вещь.

## 4. Действия игрока

| Действие | Элемент | Запрос | Результат |
|---|---|---|---|
| Отправить ход | поле ввода + Enter | `POST /api/campaign/:id/stream {input}` | текст растёт по мере генерации; затем метаданные и кнопки |
| Отправить ход без стрима | автоматически при ошибке стрима | `POST /api/campaign/:id/turn {input}` | ответ целиком |
| Перегенерировать | «⟳» | `POST .../regenerate {turn}` | страница перерисовывается, появляется вариант |
| Переписать реплику | «✎» | `POST .../edit {turn, input}` | новый ход с другим вводом, прежний ответ — вариант |
| Переключить вариант | «‹» / «›» | `POST .../variant {turn, index}` | меняются проза и состояние |
| Нарисовать кадр | «🖼» под ответом или в шапке | `POST .../image {mode:"scene"}` | картинка в ленте, запись в `illustrations` |
| Мастер-лист / портрет | кнопки в карточке | `POST .../image {mode:"card"\|"portrait", name}` | картинка в карточке |
| Карточка предмета | «◈» | `POST .../image {mode:"item", name}` | картинка в строке предмета |
| Выбросить предмет | «✕» | `POST .../drop {name}` | предмет исчезает, запись в архиве |
| Закрыть задачу | «✓» / «↷» | `POST .../quest {title, action:"done"\|"abandon"}` | статус, архив, при отказе — крючок и дебафф |
| Удалить кампанию | «Удалить» на экране историй | `DELETE /api/campaign/:id` | строка исчезает |
| Сохранить агента | «Сохранить» на экране агентов | `PUT /api/agents/:id` (+`campaign`) | статус «сохранено» |
| Сбросить агента | «Сбросить» | `POST /api/agents/:id/reset` | значения по умолчанию |
| Тест агента | «Тест» → «Отправить» | `POST /api/agents/:id/test {input}` | текст ответа, время, токены, стоимость, модель |

Все действия, меняющие кампанию, дожидаются ответа сервера и только потом обновляют панель.
Ошибка показывается всплывающим сообщением на 6 секунд (или строкой статуса в мастере).

## 5. API

Базовый адрес — `http://127.0.0.1:7801`. Тело запроса и ответа — JSON UTF-8; ключ провайдера
в браузер не передаётся. JSON-ответы API имеют `Cache-Control: no-store`; у изображений
и статики свои заголовки кэширования.

### 5.1. Кампании

| Метод | Путь | Вход | Выход | Ошибки |
|---|---|---|---|---|
| GET | `/api/campaigns` | — | массив `{id,title,preset,turn,place,savedAt,cost,tokensIn,tokensOut,cached}`, сортировка по `savedAt` убыв. | — |
| POST | `/api/campaigns` | `{id?, tone?, world?, hero?, heroName?, meta?}` | `{id, state, history:[], totals, meta}` | 409 «кампания с таким именем уже есть»; 500 без ключа |
| GET | `/api/campaign/:id` | — | `{id, state, history, totals, model, summary, map, worldMap, conspect, conspectRecent, turns}` | 404 «кампания не найдена» |
| DELETE | `/api/campaign/:id` | — | `{ok:true}` | — |
| POST | `/api/campaign/:id/turn` | `{input}` | результат хода (5.3) | 400 «пустой ход», 400 «ход слишком длинный», 404, 500 |
| POST | `/api/campaign/:id/stream` | `{input}` | SSE: `delta`, `done`, `error` | 400, 404 (до открытия потока); ошибки модели — событием `error` |
| POST | `/api/campaign/:id/regenerate` | `{turn}` | результат хода | 404 «нет снимка этого хода», 400 «нет снимка предыдущего хода» |
| POST | `/api/campaign/:id/edit` | `{turn, input}` | результат хода | 400 «пустой текст», 404, 400 |
| POST | `/api/campaign/:id/variant` | `{turn, index}` | `{ok:true, prose, state}` | 404 «нет снимка этого хода», 404 «нет такого варианта» |
| POST | `/api/campaign/:id/drop` | `{name}` | `{ok:true, state}` | 400 «не указан предмет», 404 «такого предмета нет» |
| POST | `/api/campaign/:id/quest` | `{title, action}` | `{ok:true, state}` | 404 «задача не найдена» |
| POST | `/api/campaign/:id/image` | `{mode, name?}` | `{url, mode, cost, ms, model, requestedModel, fallback, prompt, references}` | 404 «персонаж не найден» / «предмет не найден», 500 |
| GET | `/api/images/:file` | — | PNG, `Cache-Control: public, max-age=86400` | 404 «картинка не найдена» |

### 5.2. Агенты, каталог, генерация

| Метод | Путь | Вход | Выход | Ошибки |
|---|---|---|---|---|
| GET | `/api/agents` | `?id=<кампания>` (необязательно) | набор из 7 конфигураций | 404 «кампания не найдена» при неверном id |
| PUT | `/api/agents/:id` | `{model, temperature, maxTokens, prompt, enabled, everyMessages?, campaign?}` | обновлённая конфигурация | 404 «нет такого агента», 404 «кампания не найдена» |
| POST | `/api/agents/:id/reset` | `{campaign?}` | конфигурация по умолчанию | 404 |
| POST | `/api/agents/:id/test` | `{input?}` | `{text, ms, tokensOut, model, temperature, cost}` | 500 без ключа |
| GET | `/api/art-tags` | — | `{groups, selection:{include[], exclude[]}}` | — |
| PUT | `/api/art-tags` | `{include[], exclude[]}` | сохранённый выбор | — |
| GET | `/api/catalog` | — | `{tone:{groups[]}, worlds:{presets[]}}` | — |
| POST | `/api/generate/tone` | `{selections:[{group, field, value}]}` | `{text, ms, tokensOut, cost}` | 500 без ключа |
| POST | `/api/generate/world` | `{presetId?, description?, title?}` | `{text, ms, tokensOut, cost}` | 404 «пресет не найден», 500 без ключа |
| GET | `/api/stats` | — | `{campaigns[], agents{}, images, totals{...}}` | — |

### 5.3. Результат хода (ответ `turn`, `done`)

```json
{ "prose": "…", "changes": ["…"], "agentChanges": ["…"], "summarized": true,
  "problems": ["…"], "state": { }, "map": "…", "worldMap": "…",
  "totals": {"tokensIn":0,"tokensOut":0,"cached":0,"cost":0},
  "usage": {"gm":{"calls":1,"tokensIn":0,"tokensOut":0,"cost":0}},
  "stats": {"turn":1,"tokensIn":0,"cachedTokens":0,"outputTokens":0,"cost":0,"ms":0} }
```

- `changes` — журнал применённых и отброшенных изменений (включая изменения state-агента).
- `problems` — вердикт критика и ошибка разбора дельты, если были.
- `state` — состояние после хода и после state-агента.
- `stats` — цифры именно этого хода; `totals` — накопленные по кампании.

### 5.4. SSE-формат

```
event: delta
data: {"text":"…"}

event: done
data: {…результат хода…}

event: error
data: {"message":"…"}
```

Кадры разделены пустой строкой. `delta` приходит только когда ведущий пишет чистую прозу
(state-агент включён). Если state-агент выключен, поток сразу завершается событием `done`
после цельного ответа: клиент не показывает частичный текст.

## 6. Формат ошибок

Единый вид: HTTP-статус + `{ "error": "<текст>" }`. Текст — на русском, без стека и без
внутренних путей.

| Статус | Когда | Что видит игрок |
|---|---|---|
| 400 | пустой ход, ход длиннее 1200 символов, пустой текст правки, не указан предмет, нет снимка предыдущего хода | всплывающее сообщение с текстом |
| 404 | нет кампании, агента, снимка, варианта, персонажа, предмета, задачи, картинки, метода, пресета | всплывающее сообщение; экран остаётся |
| 409 | кампания с таким именем уже есть | в оверлее создания — строка ошибки; при «Начать» из списка — переход в существующую |
| 500 | нет ключа провайдера, ошибка провайдера, ошибка генерации изображения, прочее исключение | всплывающее сообщение с текстом; состояние не меняется |
| 504 | (сверх PRG, только при реализации таймаута) модель не ответила за 60 с | сообщение, ход не засчитан |

В мастере новой игры ошибки не всплывают, а пишутся в строку статуса под кнопкой:
«Ошибка: <текст>», кнопка снова доступна.

## 7. Что происходит при сбое модели

| Этап | Сервер | Клиент | Состояние и файл |
|---|---|---|---|
| Ведущий, `/turn` | исключение → 500 `{error}` | всплывающее сообщение; реплика игрока уже нарисована в ленте, но в лог не попала | ход не применён, снимок не создан, `turn` не изменён |
| Ведущий, `/stream` | поток уже открыт → событие `error` → закрытие | автоматический повтор через `/turn`; при повторной ошибке — сообщение | первый вызов ничего не записал; повторный может записать |
| Дельта не разобралась | ход продолжается, `problems` содержит «не разобрал JSON: …» | текст ошибки в метаданных ответа | состояние без изменений этого хода |
| State-агент | ошибка ловится `Promise.allSettled`, пишется в лог сервера | ответ 200; в `changes` только то, что пришло от ведущего (обычно пусто) | ход и снимок сохранены, изменения агента отсутствуют |
| Суммаризатор | ошибка ловится, `summary` не меняется | ответ 200 | конспект прошлого хода, снимок сохранён |
| Критик | проблем не исправляет | проблемы видны в метаданных | ход сохранён как есть |
| Генерация тона/мира | 500 `{error}` | строка «Ошибка: …» в мастере, кнопка разблокирована | кампания не создана |
| Изображение | откат на резервную модель; при повторной ошибке — 500 | сообщение; при успехе — «кадр готов · $…» | состояние игры не меняется, кроме URL кадра |
| Нет ключа | 500 на всех эндпоинтах, которым нужна модель | сообщение «нет OPENROUTER_API_KEY в .env» | чтение кампаний и статика работают |

Отдельно: после неудачного хода реплика игрока остаётся в ленте до перезагрузки страницы,
хотя в состоянии её нет. Это расхождение ленты и состояния — известное ограничение PRG.

## 8. Что в PRG отсутствует или сделано наполовину

**API.**

- Нет аутентификации, авторизации, CSRF-защиты и ограничения частоты запросов; сервер слушает
  только петлевой адрес, поэтому это осознанное решение для локального стенда.
- Нет блокировки кампании: два одновременных хода могут перетереть состояние и снимки.
- Нет таймаута и отмены вызовов ведущего, state-агента и суммаризатора; зависший провайдер
  держит запрос бесконечно.
- Нет повторов на 429/5xx и нет отмены хода игроком.
- Цены считаются по модели из переменной окружения, а не по модели каждого агента.
- `POST /api/agents/:id/test` тестирует глобального агента, игнорируя настройки кампании.
- Иллюстраторы берутся из глобальных настроек: правка `artist*` внутри игры на рисование
  не влияет.
- `GET /api/campaign/:id` возвращает `conspect`, `conspectRecent`, `summary` и `model`,
  но клиент их не показывает: поля нужны для отладки.
- `GET /api/catalog` отдаёт пустой `worlds.presets`; эндпоинт генерации мира без
  `description` и без валидного `presetId` отвечает 404.

**Интерфейс.**

- Нет кнопки отмены выполняющегося хода и нет прогресса после окончания прозы: ожидание
  state-агента и суммаризатора невидимо, блок действий появляется только после `done`.
- Нет кнопки повтора после ошибки: только всплывающее сообщение.
- Нет подтверждения стоимости перед рисованием кадра; цена видна после.
- Лента не виртуализирована и не разбита на страницы.
- Нет переименования кампании, экспорта, поиска по истории, настроек темы и локализации.
- Экран историй показывает id кампании, а не `meta.title`.
- В мастере коллизия id даёт ошибку в строке статуса, а не предложение открыть существующую.
- Остались неиспользуемые остатки каталога миров: массив `TEMPLATES` (6 карточек),
  функции `viewCatalog`, `viewCatalog2`, `presetCard`, `catalogCache`.
- Мобильный вид: панель показывается под лентой, без свайпа и без сохранения позиции прокрутки.

- `scripts/unit-test.mjs` покрывает только применение дельты.

- Нет тестов на сборку контекста, критик, конспект, хранилище, откаты и ошибки API.
